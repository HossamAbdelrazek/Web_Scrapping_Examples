# Web Scrapping Tasks

This repository contains several web scrapping tasks performed using Python and Jupyter Notebooks. The tasks involve extracting data from various websites and exporting the results into CSV files for further analysis.

## Overview

The repository includes the following files:

- **Amazon_india_books.ipynb**  
  A notebook that scrapes book data from Amazon India—extracting details like title, author, price, and rating—and saves the results into a CSV file.

- **Scrapping_amazon_laptops_1_page.ipynb**  
  A notebook dedicated to scraping data on laptops from a single page on Amazon. The notebook extracts details such as brand, model, price, and specifications, then exports the data to a CSV file.

- **Scrapping_box_office_top200.ipynb**  
  A notebook that scrapes information on the top 200 box office movies. It gathers data like movie titles, release dates, and earnings, and saves the results as a CSV file.

- **amazon_india_books.csv**  
  CSV file containing the scraped data for books from Amazon India.

- **amazon_laptops_data.csv**  
  CSV file with the scraped data for laptops from Amazon.

- **Box_office_top200.csv**  
  CSV file containing the scraped data for the top 200 box office movies.
